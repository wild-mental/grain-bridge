# **App Name**: GrainBridge

## Core Features:

- Smart Matching: AI-powered matching tool to identify and rank the optimal pairings of surplus and shortage regions based on factors such as distance, tonnage, and cost, and relevant geopolitical situations, creating dynamic recommendations for resource allocation.
- Interactive Dashboards: Interactive map visualizations displaying real-time grain surplus and shortage data, overlaid with relevant indicators such as IPC levels and crisis alerts, for intuitive monitoring of global food supply.
- Easy Donations: Streamlined donation workflow using Stripe for secure transactions, enabling users to fund specific shipments with transparent cost breakdowns and unit pledges.
- Impact Visualization: Impact tracking and visualization to show the impact of donations. This includes cumulative tonnage moved, the percentage of hunger risk averted, and an animated map to visualize progress.
- Auditable Ledger: A transparent, auditable ledger system using PostgreSQL with a hash chain to provide a tamper-proof record of all transactions and shipments, ensuring accountability and trust in the platform's operations.
- Mobile Responsiveness: Mobile-responsive design, to ensure accessibility, with a streamlined UX that guides visitors to dashboards, impact boards, or donation opportunities, across a variety of screen sizes and device types.

## Style Guidelines:

- Primary color: Earthy beige (#D2B48C), evoking themes of harvest, stability, and global resources.
- Background color: Soft off-white (#F5F5DC) providing a clean and neutral backdrop to highlight data visualizations.
- Accent color: Muted olive green (#808000) as a secondary hue to bring attention to key actions, with a visual tie to themes of food and humanitarian action.
- Font pairing: 'Playfair' (serif) for headlines to create a modern high-end feel, complemented by 'PT Sans' (sans-serif) for body text for maximum legibility. 
- Use clear, universal icons sourced from a consistent set (e.g. Font Awesome or Material Design) to represent commodities, regions, and donation actions, optimized for legibility at various sizes.
- Implement a responsive, grid-based layout to adapt content to various screen sizes. Prioritize key metrics (surplus/shortage volumes, donation progress) with prominent placement.
- Use subtle transitions and loading animations to enhance user experience, such as map transitions when filtering by region and smooth updates to the impact infographic as shipments are completed.
